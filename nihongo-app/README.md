# 일본어 마스터 (Nihongo Master)

히라가나부터 JLPT N1까지 한 앱으로 공부하는 안드로이드 앱입니다. 인터넷 없이 동작하고, 학습 기록은 기기 안에만 저장됩니다.

## 📱 설치

1. 휴대폰에서 **[최신 릴리스 페이지](https://github.com/Joyong133/Gta-vr/releases/latest)** 를 열고 `nihongo-master.apk` 를 받습니다.
2. 다운로드 알림을 눌러 설치합니다. 처음이면 "출처를 알 수 없는 앱 설치"를 허용해야 합니다.
3. 새 버전을 설치하면 기존 앱 위에 업데이트되고 학습 기록은 그대로 남습니다.

> 발음이 나오지 않으면 **설정 → 일본어 음성(TTS) 엔진 설정**에서 Google 음성 서비스의 일본어 음성을 설치하세요.

## 두 가지 학습 과정

| | 📘 체계 코스 | 🎮 챌린지 로드 |
|---|---|---|
| 방식 | 강의를 읽고 이해한 뒤 테스트 | 짧은 게임식 레슨을 반복 |
| 구성 | 단원마다 문법 강의 · 단어 · 한자 · 회화 · 독해 · 단원 테스트 | 유닛별 노드(단어/문법/한자/회화/이야기/보스) 경로 |
| 동기 부여 | 단원 테스트 80% 이상이면 통과 | 하트 ❤️, XP, 연속 학습 🔥, 왕관 👑, 주간 리그, 업적, 젬 상점 |
| 문제 유형 | 문법 확인 문제, 독해 문제 | 뜻·단어 고르기, 읽기, 듣기, 짝 맞추기, 문장 조립(일→한, 한→일, 받아쓰기), 빈칸, 말하기 |

두 과정은 같은 콘텐츠를 공유합니다. 챌린지 로드의 각 유닛에서 **📘 강의** 버튼을 누르면 해당 체계 코스 단원으로 바로 이동합니다.

## 콘텐츠 규모

| 레벨 | 단원 | 문법 | 단어 | 한자 | 독해 | 회화 |
|---|---|---|---|---|---|---|
| 문자 | 9 | — | 150 | — | — | — |
| N5 | 12 | 60 | 564 | 103 | 5 | 62줄 |
| N4 | 12 | 55 | 442 | 179 | 4 | 57줄 |
| N3 | 12 | 53 | 452 | 222 | 7 | 29줄 |
| N2 | 12 | 58 | 456 | 206 | 7 | 24줄 |
| N1 | 12 | 59 | 440 | 190 | 7 | 20줄 |
| **합계** | **69** | **285** | **2,504** | **900** | **30** | **192줄** |

- 문법마다 한국어 설명, 접속 형태, 주의점, 후리가나가 달린 예문, 확인 문제가 있습니다(확인 문제 327개, 예문 659개).
- 한자는 음독·훈독과 한국 한자음(훈음), 대표 단어를 함께 보여 줍니다.
- 가나는 50음도, 탁음, 요음, 외래어 표기까지 다루고, 글자마다 유래 한자와 기억법을 붙였습니다.

## 그 밖의 기능

- 🔁 **SRS 복습**: 간격 반복 플래시카드(다시/어려움/좋음/쉬움), 스와이프 채점, 퀴즈형 복습, 7일 예정표
- ❌ **오답 노트 · ⭐ 즐겨찾기**: 틀린 문제와 별표한 항목을 모아 퀴즈로 다시 풀기
- 📝 **JLPT 모의고사**: 레벨별 문자·어휘 / 문법 / 독해 / 청해, 제한 시간, 180점 환산, 합격 판정, 오답 해설
- 🧘 **집중 모드**: 뽀모도로 타이머(화면 이동해도 유지), 빗소리·파도·모닥불·백색 소음, 화면 꺼짐 방지
- ✍️ **쓰기 연습**: 가나·한자를 손가락으로 따라 쓰고 일치도 채점
- 🔎 **사전 검색**: 단어·한자·문법을 일본어/한국어/읽기로 통합 검색
- 📊 **통계**: 7일 XP 그래프, 16주 학습 잔디, 레벨별 진도, 누적 학습 시간
- 🔔 **매일 학습 알림**, 다크 모드, 후리가나 켜기/끄기, 발음 속도 조절, 백업 파일 저장·불러오기

## 개발

```
nihongo-app/
├── web/                 # 앱 화면 (HTML/CSS/JS, 빌드 도구 없음)
│   ├── data/            # 학습 콘텐츠 (kana, n5~n1, vocab-plus, extra)
│   ├── js/              # 엔진 (저장소·SRS·게임화·문제 생성·화면)
│   └── index.html
├── android/             # WebView 셸 (TTS·음성 인식·진동·알림·백업 브릿지)
├── tools/validate-data.mjs   # 콘텐츠 형식 검사
└── tests/               # 브라우저 자동 테스트
```

- 브라우저에서 바로 실행: `nihongo-app/web/index.html` 을 열면 됩니다.
- 콘텐츠 검사: `node nihongo-app/tools/validate-data.mjs`
- 화면 흐름 테스트: `node nihongo-app/tests/smoke.mjs`
- 전체 문제 생성 검사: `node nihongo-app/tests/exercises.mjs`
- APK 빌드: `nihongo-app/**` 가 바뀐 커밋을 푸시하면 GitHub Actions(`.github/workflows/nihongo-apk.yml`)가 서명된 APK를 만들어 릴리스에 올립니다. 로컬에서는 Android SDK가 있는 환경에서 `cd nihongo-app/android && gradle assembleRelease`.

### 서명 키

업데이트 설치가 끊기지 않도록 고정된 개인용 서명 키(`android/keystore/nihongo-release.jks`)가 저장소에 들어 있습니다. 공개 저장소이므로 다른 사람도 같은 키로 서명할 수 있다는 점은 알아 두세요. 저장소 Secrets에 `NIHONGO_KEYSTORE_B64`, `NIHONGO_KEYSTORE_PASSWORD`, `NIHONGO_KEY_ALIAS`, `NIHONGO_KEY_PASSWORD` 를 등록하면 CI가 그 키를 대신 사용합니다. 키를 바꾸면 기존 앱을 지우고 새로 설치해야 하므로, 바꾸기 전에 앱의 **설정 → 백업 내보내기**로 기록을 저장하세요.
