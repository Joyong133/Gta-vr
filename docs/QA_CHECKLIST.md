# 헤드셋 수동 QA 체크리스트

자동 테스트(`npm run test:all`)가 로직과 WebXR 코드 경로를 확인합니다. 아래 항목은 **실제 헤드셋에서만** 판단할 수 있는 체감·성능·편안함 항목입니다. 각 항목 옆에 결과(통과/문제/메모)를 적으세요.

준비: Quest Link/SteamVR + Chrome/Edge(`npm run dev` → `localhost:5173`) 또는 Quest 브라우저(HTTPS 배포 주소 / `adb reverse`). 손목 메뉴 → 시스템 → **디버그 표시**를 켜면 FPS·프레임 시간·CPU 구간·드로우콜·GPU 시간(지원 시), 경찰/보행자/교통 상태가 왼쪽 위에 떠 있습니다.

## 2. 요구 상황별 테스트

| 상황 | 방법 | 기대 결과 | 결과 |
|---|---|---|---|
| 한 손 / 양손 물체 조작 | 쓰레기통·상자를 한 손으로 들다가 다른 손으로 함께 잡기, 한 손 놓기 | 떨림 없이 들림, 핸드오버 시 튀지 않음, 놓으면 물리로 떨어짐 | |
| 던지기 | 콘·캔을 휘둘러 놓기 | 손 속도대로 날아감(과도하지 않음) | |
| 블래스터 양손 조준 | 블래스터를 잡고 다른 손으로 앞 손잡이(분홍) 잡기 | 두 손을 잇는 방향으로 조준 | |
| 미션 중간 재시작 | 손목 메뉴 → 상태 → `미션 재시작` | 첫 목표로 돌아가고 아이템 재배치, 수배 해제 | |
| 차량 전복 | 고속으로 연석/소품에 충돌하거나 콘솔 `neon.flipCar()` | 계기판에 "차량 전복 — [X] 복구", X → 페이드 후 도로 위 정자세 | |
| 벽에 끼임 | 건물 벽에 정면으로 붙여 가속 유지 | 약 3초 후 "끼임 감지" → X로 도로 복구 | |
| NPC 경로 차단 | 인도 위에 서서 보행자 길을 막기 / 차선에 차를 세워 두기 | 보행자는 비켜 가거나 되돌아감, 교통 차량은 정지·경적 후 반대 차선으로 추월 | |
| 경찰이 플레이어를 놓침 | 수배 중 건물 뒤로 숨기 | 디버그에서 경찰 상태 pursue → search, 손목 지도에 수색 원, 시간이 지나면 해제 | |
| 저장 파일 없음/손상 | 손목 메뉴 → 시스템 → `저장 손상 테스트(QA)` → `마지막 저장 불러오기` / `저장 데이터 초기화` | 백업에서 복구 또는 기본값으로 안전 시작 | |
| 앉은 자세 | 의자에 앉아 손목 메뉴 → 편안함 → `자세: 앉아서` → `키 보정` | 눈높이가 서 있을 때와 비슷해짐(약 1.6 m), 바닥 물건은 원거리 잡기로 집기 | |
| 왼손잡이 | `주 사용 손: 왼손` | 이동/회전 스틱, 가속/브레이크 트리거, 손목 메뉴 손이 서로 바뀜 | |
